# Personal portfolio

A minimal, light-themed portfolio for Uday Agarwal, built with Next.js, TypeScript, Tailwind CSS, and shadcn/ui.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Edit the content

Portfolio links, projects, experience, education, and skills live in `src/data/portfolio.ts`.

## Production

```bash
npm run build
npm run start
```
